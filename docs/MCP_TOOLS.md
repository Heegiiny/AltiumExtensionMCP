# MCP tools

All tools are read-only, idempotent and return JSON text content. On failure the result has
`isError: true` and the text is `{"error":{"code","message"},"details":{...hints}}`.
Absent boolean/number fields in results mean `false`/`0` (compact wire format, see DECISIONS D6).

Bridge method names (used by `AltiumMcp.Server --call <method>`) are listed next to each tool.

## Connection

| Tool | Bridge method | Input | Output |
|------|---------------|-------|--------|
| `altium_ping` | `system.ping` | – | `status, bridgeVersion, processId, serverTime, uptimeSeconds, requestsServed` |
| `altium_get_environment` | `system.getEnvironment` | – | `productName, productVersion, platformVersion, executablePath, processId, extensionModuleName, bridgeVersion, dotNetRuntime, isInitialized, loadedServerModules[], technologySetCount` |
| `altium_bridge_diagnostics` | (local, no Altium call) | – | `resolvedBaseUrl, resolvedFrom (env/discoveryFile/defaultPort), discoveryFilePath, discoveryFileExists, descriptor, descriptorProcessAlive, altiumProcesses[], lastError, hints[]` |

## Workspace

| Tool | Bridge method | Input | Output |
|------|---------------|-------|--------|
| `altium_get_workspace` | `workspace.getInfo` | – | `workspaceFileName, workspaceFullPath, projectCount, installedLibraryCount, focusedProject{path,name,kind,isFocused}, focusedDocument{path,fileName,kind,projectPath}, activeViewDocumentPath` |
| `altium_list_projects` | `workspace.listProjects` | – | `projects[]{ref, logicalDocumentCount, physicalDocumentCount, generatedDocumentCount, variantCount, needsCompile, inCompilation, outputPath, managedGuid}`, `focusedProjectPath` |
| `altium_list_open_documents` | `workspace.listOpenDocuments` | – | `documents[]{ref, isLoaded, isOpenInEditor, isModified, isFocused}`, `focusedDocumentPath` |

`kind` values seen: `PrjPcb`, `FreeDocuments`, `SCH`, `PCB`, `OUTPUTJOB`, `Harness`, `VirtualBOM`,
`Annotation`, `ProjectGroup`, `Engagement` (home page).

## Project (compiled model)

Common inputs: `projectPath?` (full path; default = focused project), `compileIfNeeded?` (default false;
when true and no compiled model exists the project is compiled — the only state-changing option).

| Tool | Bridge method | Input | Output |
|------|---------------|-------|--------|
| `altium_get_project_structure` | `project.getStructure` | common | `project, logicalDocuments[]{ref, componentCount, netCount, sheetSymbolCount, portCount, indentLevel, isPrimaryImplementationDocument, ...}, generatedDocuments[], hierarchy[]{path, fileName, instanceName, indentLevel, componentCount, netCount, children[]}, variants[], parameters{}, violations{total, byErrorLevel{}, byErrorKind{}, sample[<=10]{errorKind, errorLevel, description, documentPath}}, primaryImplementationDocument, isCompiled` |
| `altium_list_components` | `project.listComponents` | common + `filter?`, `includeParameters?`, `offset?`, `limit?` (default 100, max 2000) | `projectPath, total, offset, returned, components[]{id, designator, logicalDesignator, comment, description, libraryReference, sourceLibraryName, footprint, partType, documentPath, pinCount, subPartCount, parameters?}` |
| `altium_get_component` | `project.getComponent` | common + `component` (UniqueId or designator) | `summary{...as above}, pins[]{number, name, electrical, net, partId, isHidden}, implementations[]{modelType, modelName, description, isCurrent}, parameters{}` |
| `altium_list_nets` | `project.listNets` | common + `filter?`, `includePins?`, `offset?`, `limit?` | `projectPath, total, offset, returned, nets[]{name, pinCount, portCount, netLabelCount, powerObjectCount, isLocal, isAutoGenerated, electrical, documentPath, pins?[]}` |
| `altium_get_net` | `project.getNet` | common + `net` (name) | `NetSummary` + `pins[]{designator, pin, pinName, electrical}` |

Filter semantics (`FilterMatcher`): plain text → case-insensitive substring; contains `*`/`?` →
wildcard anchored to the whole field. Components match on designator, logicalDesignator, comment,
libraryReference, footprint, description; nets on name.

Sorting: components by natural designator order (R2 < R10); nets by name.

## Error codes

| Code | Meaning | Typical hint |
|------|---------|--------------|
| `BRIDGE_UNAVAILABLE` (server-side) | Cannot reach the bridge | start Altium with `-RAltiumExtensionMCP:StartBridge`; open panel; stale file |
| `ALTIUM_BUSY` | UI thread did not answer within 60 s | retry later |
| `NO_WORKSPACE` | Workspace manager not available yet | wait for Altium to finish loading |
| `NO_ACTIVE_PROJECT` | No focused project and none given | open a project / pass projectPath |
| `PROJECT_NOT_FOUND` | `projectPath` not open in the workspace | use `altium_list_projects` |
| `NOT_COMPILED` | No compiled (flattened) model | `compileIfNeeded=true` or Project > Validate |
| `OBJECT_NOT_FOUND` | Component / net not found | use the list tool with a filter |
| `INVALID_PARAMS` | Missing/invalid parameter | message names the parameter |
| `UNKNOWN_METHOD` | Server/extension version mismatch | redeploy both |
| `INTERNAL` | Unexpected exception; `details` has type, message, stack | report/inspect log |

## Planned (not implemented)

Phase 1 continuation — read-only:
- `altium_get_document` / `altium_list_sheet_objects` — schematic object model (`ISch_Document`
  iterators: components, wires, net labels, ports, power ports, parameters, positions).
- `altium_get_component_parameters_bulk` — parameters for many components in one call (BOM view).
- `altium_get_pcb_summary`, `altium_list_pcb_components`, `altium_list_pcb_nets`, `altium_get_layer_stack`,
  `altium_get_pcb_component` (position/rotation/layer/footprint) — `IPCB_Board` via `PCBServer`.
- `altium_get_design_rules`, `altium_run_drc_summary`, `altium_get_erc_report`.
- `altium_list_libraries` / `altium_get_library_symbol` — installed and project libraries; managed
  component links (`Altium Content Vault` / Workspace items, `DM_VaultGUID` & co.).
- `altium_get_variants` — variant list and per-variant component substitutions.
- `altium_get_workspace_server` — On-Prem/365 connection state (`IWorkspace`/`EDMS` interfaces).
- `altium_search` — cross-object text search (designator/comment/net) returning refs only.

Phase 2+ — writes (each with `dryRun`, returns a ChangeSet):
- `altium_set_component_parameter`, `altium_set_component_comment`.
- Schematic placement/wiring, PCB move/rotate, rules — see ROADMAP.

Toolsets (planned mechanism): group by class (`connection`, `workspace`, `project`, `schematic`,
`pcb`, `library`, `verify`, `edit`) and expose only `connection`+`workspace`+`project` by default,
with a meta-tool to enable others (or a `--toolsets` server switch).
