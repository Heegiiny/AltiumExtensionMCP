# Protected Review Notes

This directory contains user-approved design findings and implementation requirements.

- Treat every file under `review-notes/` as read-only reference material.
- Do not create, edit, rename, move, or delete files in this directory.
- Implementation work belongs elsewhere in the repository.
- A direct, explicit user request to update these notes is the only exception.
- When code and these notes disagree, report the discrepancy instead of silently rewriting the notes.
